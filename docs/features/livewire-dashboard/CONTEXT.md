# Domain Context — livewire-dashboard

## Glossary

- CLI run — one execution of a test-ai CLI command, with a fixed status and timing, that the dashboard visualizes. NOT the AI test/scenario the command runs — that's a different concept, the run is the technical execution of the command.
- developer — the person who runs test-ai CLI commands and reviews their results, including through the dashboard. NOT a role with distinct permissions — there is no authorization in this feature, developer is the single actor.
